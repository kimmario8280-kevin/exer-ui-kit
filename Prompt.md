-------------------------------------------
이 프로젝트는 새로운 정적 프론트엔드 UI 컴포넌트 레퍼런스/플레이그라운드를 구축하기 위한 것이다.  
아직 구현되지 않은 최종 산출물(ui-kit-playground.html)을 만들기 위한 
**미래 지향적 설계 명세서(Requirements Specification)** 문서인 CLAUDE.md를 작성하라.

CLAUDE.md는 “현재 구현(index.html 등)을 설명하는 문서”가 아니라,
앞으로 개발자가 따라야 할 **구조, 데이터 모델, 레이아웃, 렌더링 방식, 디자인 규칙, 참고 리소스 사용 방식**을 정의하는
설계 중심 문서여야 한다.

문서에는 다음 요구사항을 반드시 포함한다:

1. **프로젝트 개요**
   - CareerFoundry UI Element Glossary 기반 32 UI 컴포넌트 + 공통 UX 레이어 컴포넌트(경고, 확인, 알림, 토스트, 스낵바, 바텀 시트 등)
   - 최종 산출물은 단일 self-contained HTML 파일(ui-kit-playground.html)

2. **레이아웃 요구사항**
   - 좌측: UI 요소 리스트 + 공통 UX 레이어 컴포넌트 목록
   - 우측: 선택한 컴포넌트의 이름, 정의/설명, 그리고 Preview / HTML / CSS / JS 탭

3. **데이터 모델 설계**
   - 모든 컴포넌트를 하나의 배열로 관리
   - 각 요소는 { id, num, name, nameKo, cat, desc, usecase, feature, html, css, js } 구조

4. **렌더링 방식**
   - 탭 전환은 display 토글 방식
   - 미리보기는 iframe srcdoc으로 HTML/CSS/JS를 격리하여 렌더링
   - 코드 하이라이트는 highlight.js 사용
   - 복사 버튼은 navigator.clipboard.writeText()

5. **CSS 작성 규칙**
   - Tailwind 등 외부 유틸리티 클래스 사용 금지
   - self-contained semantic class(.accordion, .btn, .modal-box 등)로 작성
   - 복사·이식성 극대화

6. **디자인 규칙**
   - anti-ai-slop 규칙을 강제 적용
   - 그라데이션, 컬러 그림자, 글로우, 과도한 모션, 배경 장식 금지
   - 무채색 + 단일 액센트 컬러
   - border, spacing, typography 중심의 위계

7. **참고 리소스 파일의 역할 정의**
   - @docs/resource/component-portfolio.html → 전체 구조의 정본 참고
   - @docs/resource/ui-component.html → 레이아웃 아이디어 참고
   - @docs/resource/ui-components-32-catalog.html → 32 컴포넌트 데이터 모델 참고
   - @docs/resource/label-chip-system.html → 색상/칩 시스템 참고
   - @docs/resource/alert-ui-showcase.html → UX 레이어 컴포넌트 동작 참고(비주얼은 재작성)

8. **문서 형식**
   - 한글로 작성
   - 미래 지향적 설계 문서로 작성
   - 구현 설명 금지, 설계·요구사항 중심으로 작성
